# Project Proposal

- **Due:** Friday by 11:59pm
- **Points:** 1
- **Submitting:** A file upload

Please submit your project proposal in PDF format by the date configured for this assignment. The project description and project proposal requirements are described [here](./Project_Proposal_Requirements.md).

---

## Purpose

The proposal ensures that the project is specific, feasible, and appropriate for the course. Students must submit proposals individually. Peer support groups will be assigned after the proposals have been reviewed.

---

## Required Submission

The proposal should include:

- Project title
- Use case
- Target users
- What the assistant will help users do
- Planned external data source or tool
- Planned LLMs or system configurations to compare
- At least 20 draft user queries
- Initial safety, security, or robustness concerns
- Expected challenges

---

## Proposal Specifications

### A proposal is **Complete** when it:

- Defines a specific and realistic use case
- Identifies a target user group
- Includes a plausible plan for using an external data source or tool
- Identifies at least two models or system configurations to compare
- Includes at least 20 draft user queries
- Identifies at least one likely challenge or risk
- Provides enough detail for the instructor to determine whether the project is feasible

### A proposal is **Incomplete** if:

- The scope is too broad or vague
- The project is not sufficiently focused on NLP or LLMs
- The proposal does not include a data or tool plan
- The proposal does not include a model or configuration comparison plan
- The required query set is missing
- There is not enough information to determine project feasibility

> An "Incomplete" grade means that a revised proposal is expected before the next project check-in.
